# Сиброад - городская концепция

Второй вариант корпоративного сайта ООО «Сиброад» в тёмной городской стилистике.

Готовая статическая версия находится в каталоге `dist`. Публикация GitHub Pages выполняется автоматически после обновления ветки `main`.

Проект включает отдельные изображения и адаптивную композицию для компьютеров и мобильных устройств.
